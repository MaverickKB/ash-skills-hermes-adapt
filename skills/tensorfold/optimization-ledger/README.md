# Optimization ledger

Block repeat dead ends, score mirrored `B, C, C, B` TensorFold benchmarks with thermal and token-hash checks, and track cross-family `OWED_PORT` speedups.

## When to use it

You are iterating on TensorFold performance across sessions and want an executable memory of wins and losses, strict mirrored A/B verification and a prioritized porting queue across Metal, CUDA and sibling model families.

## Try it

```text
Use optimization-ledger. Run preflight on our candidate mechanism, score the mirrored B,C,C,B receipt with thermal drops and token hashes, record the outcome, and list owed ports.
```
