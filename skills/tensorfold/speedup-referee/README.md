# Speedup referee

Independently reviews whether a claimed speedup holds under the same workload and output contract.

## When to use it

You're reviewing a performance claim before merging it or publishing the numbers.

Check whether the changed path actually ran, whether the gain exceeds measured noise, and whether another workload slowed down.

## What's included

Use the verification checklist with the original benchmark output and correctness evidence.

Open [SKILL.md](SKILL.md) for the full instructions.
